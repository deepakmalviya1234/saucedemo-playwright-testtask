# Test Case Suite — E2E Flow: Login → Cart → Checkout → Order Confirmation

**Application under test:** https://www.saucedemo.com/ (Swag Labs demo storefront)
**Scope:** One end-to-end purchase flow, from authentication through order completion.
**Credentials (from login page):** username `standard_user` (and other listed users), password `secret_sauce`.

## Legend

- **Priority:** P1 = critical / blocks the core flow, P2 = important / degrades experience, P3 = minor / edge or cosmetic.
- **Type:** Positive (valid path), Negative (invalid input / error handling), Boundary (limits / edge values), Cross-field (validation across multiple fields).
